# E&N Service Company — website

A single-page, dependency-free site laid out like apple.com: a translucent bar, full-width
photo tiles with one headline and one line each, a two-up grid, a quiet footer.

- `index.html` — the page.
- `styles.css` — one stylesheet; works down to phone width.
- `assets/` — favicon and photos (Unsplash, free license).

No build step. Serve the folder (`python3 -m http.server`) and visit http://localhost:8000.
Published by GitHub Pages from `main` / root: https://lman80.github.io/en-service-website/
